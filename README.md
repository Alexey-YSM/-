1. Вначале проекта введены 1 константа, показывающая размер игрового поля, затем 3 переменные: первые 2 показывают нахождение игроков, третья - чей сейчас будет ход
2. Далее создаем само поле, заполненное "0", потом добавляем туда отрицательные значения (змеи) и положительные значения (лестницы)
3. Функция, в которую передаются 2 переменные - местонахождения игроков на поле. Эта функция создает красивое поле в консоли, показывает перемещения игрков после каждого хода
4. Далее идет цикл, который повторяется пока один из игроков не выиграет. Внутри него генерируется случайное число от 1 до 6 и игрок перемещается на столько клеток, сколько выпало "на кубике". В конце цикла берется отрицание от move, чтобы сменить ход игрока (если move - True, то ходит игрок 1, если False - ходит игрок 2)
